KelimeLab PWA — Kurulum

1. ZIP dosyasını açın. index.html, sw.js, manifest.webmanifest ve iki ikon dosyasını aynı klasörde tutun.
2. GitHub üzerinde yeni bir herkese açık depo açın (ör. kelimelab). Bu beş dosyayı depo kök dizinine yükleyin.
3. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save.
4. Yayımlanan https://KULLANICI.github.io/kelimelab/ adresini Safari’de açın.
5. Paylaş > Ana Ekrana Ekle > Ekle.
6. Eski HTML sürümünde yedek dışa aktarın, PWA’da yedeği geri yükleyin. İlerleme farklı adreslerde otomatik taşınmaz.

Not: GitHub Pages ücretsiz herkese açık yayın yapar. Kişisel bilgileri veya kayıt dosyalarını depoya yüklemeyin. İlk açılışta internet gerekir; sonraki açılışlarda önbellek çevrimdışı çalışmayı destekler.
